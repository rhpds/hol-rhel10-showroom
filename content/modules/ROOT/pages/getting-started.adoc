== Getting Started (DO THIS FIRST!)

These steps should be easy to click-through if you are using the showroom terminal.

Launch a 'tmux' (terminal multiplexer):

[{format_cmd}]
----
workshop-tmux.sh TERM1
----

Using tmux will allow you to return to where you were should you get disconnected, and whatever was running will still be running or will have completed uninterrupted.  To reattach to a tmux session use:

[{format_cmd}]
----
tmux a
----
(a for attach)
