== What You've Learned

Throughout this workshop, you've gained hands-on experience with:

* **Package Management**: Installing, updating, and managing software with dnf
* **Service Management**: Controlling system services with systemd
* **Storage Management**: Configuring advanced storage with Stratis and LVM-VDO
* **Firewall Management**: Securing systems with firewalld and nftables
* **Container Technologies**: Building and managing containers with Podman, Buildah, and Skopeo
* **Image Mode and Bootable Containers**: Creating bootable container images for immutable infrastructure
* **Virtualization**: Managing virtual machines with libvirt and Image Builder
* **RHEL Lightspeed**: Leveraging AI-assisted system administration
* **Security and Monitoring**: Session logging with tlog and eBPF tracing for performance analysis
* **System Upgrades**: Performing in-place upgrades with LEAPP
* **Boot Management**: Managing boot configurations with Boom
* **Web Console**: Using Cockpit for graphical system management

You're now equipped to deploy, manage, and troubleshoot Red Hat Enterprise Linux 10 systems effectively.
